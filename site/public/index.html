Install

  1. Install Fabric Loader for Minecraft 1.21.11.
  2. Drop fabric-api-0.141.6+1.21.11.jar into your instance's mods folder.
  3. Drop donutsmp-rtp-mapper-1.3.0.jar into the same mods folder.
  4. Launch the Fabric profile, join a world, then press Right Shift or click RTP Mapper in the Esc pause menu.

Open the mapper

  • Right Shift in game — rebindable in Options → Controls → Key Binds.
  • Esc → RTP Mapper button, bottom-left of the pause menu.
  • /rtpmapper status prints state in chat without opening the GUI.

The JAR is client-side only. It does not automate movement, combat or inventories, and the optional Baritone mining controller is off by default — only enable it where the server permits it. Follow DonutSMP's current rules.
